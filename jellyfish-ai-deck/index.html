The Problem

Multi-agent AI is exploding in cost

Modern AI products run fleets of autonomous agents — planners, researchers, coders, reviewers — that pass context, instructions, and results between each other. Every hop is an LLM call.

A single user action can trigger 10–50 inter-agent LLM calls. Most of the tokens in these messages are redundant context, verbose instructions, and repeated information.

Common in AutoGPT, CrewAI, LangGraph, OpenAI Swarm, and custom agent frameworks.

And agents have no guardrails

When agents run autonomously, there’s no human reviewing every prompt before it hits an LLM:

  • Data leaks — agents accidentally include PII, credentials, or internal data in prompts
  • Budget overruns — runaway agent loops burn thousands of dollars in minutes
  • Off-topic drift — agents wander outside their assigned domain
  • Compliance gaps — no audit trail of what agents sent to external LLMs

Teams need both cost control and safety guardrails — today they have neither.

Our optimization pipeline (today)

  1. Segmentation — parse prompt into system, context, and query regions
  2. Entropy scoring — heuristic token importance scoring inspired by LLMLingua perplexity approach
  3. Context dedup — detect repeated info across agent handoff messages, prune redundancy
  4. Extractive compression — remove filler words, tighten structure (inspired by FrugalPrompt/TRIM)
  5. Externalization — move long content to paste links; agent reads link, no tokens wasted
  6. Policy check — validate against all active user policies before returning

Current: heuristic-based. Next: fine-tuned small models for neural compression (distilbert/phi-2 for perplexity scoring).

Where we are vs. where we’re going

  • Today: heuristic compression (entropy scoring, filler removal, context dedup) — effective on verbose/redundant prompts
  • Honest limitation: short, well-written prompts don’t compress much — the value there is policy enforcement, not compression
  • Next: neural compression with small LMs (distilbert/phi-2 for perplexity-based token scoring)
  • Next: task-aware + query-aware methods that outperform one-size-fits-all
  • Research shows 20–80% compression is achievable — we’re building toward this with proper ML models

Competitive Landscape

Why not existing tools?

LLM Providers (OpenAI, Anthropic)

Offer prompt caching (50% off repeated prefixes) — helps with static parts, but doesn’t compress unique content. No cross-provider solution. No policy engine.

LLM Gateways (Portkey, Helicone)

Focus on observability + routing, not prompt optimization. No compression science. Logging ≠ cost reduction.

DIY prompt engineering

Manual, not scalable. Doesn’t work for autonomous agents that generate their own prompts at runtime.

Jellyfish AI

Research-backed compression + policy enforcement + drop-in API. Built specifically for multi-agent systems. Provider-agnostic. On-prem option.

Our moat (honest assessment)

  • Policy engine — no competitor offers prompt-level guardrails for autonomous agents. High switching cost once deployed.
  • Compression is complementary to caching — caching helps repeated prefixes; we optimize the unique parts. Used together, savings compound.
  • Multi-agent native — built for inter-agent communication, not just human→LLM
  • On-prem / privacy-first — Ollama + Docker means prompts never leave customer infra
  • Moat deepens with ML — neural compression (next milestone) creates a data flywheel: more prompts → better models → wider moat

Elephant in the room: falling prices

“LLM token prices have dropped ~100× in 2 years. Won’t this problem solve itself?”

  • Per-token prices fall, but total token volume grows faster. Multi-agent = N agents × M hops × K tokens. Absolute spend keeps rising.
  • Cheap tokens make more agent usage viable → more agents → more total cost → more need for controls.
  • Even at $0 per token, you still need guardrails. Policy enforcement value is independent of token price.
  • This is why we lead with policy engine as the wedge and offer compression as bonus value — the guardrails sell regardless of price trends.
