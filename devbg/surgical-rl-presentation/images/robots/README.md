# Robot images

The three overview slides in Part 2 (Teleop Giants, Specialty, Open Research)
show each robot as an image + title only. Drop a photo at the expected
path and it'll show up; the slide falls back to a dark placeholder
showing the expected filename until then.

| Filename                       | Robot                              |
| ------------------------------ | ---------------------------------- |
| `images/robots/da-vinci.jpg`   | Intuitive da Vinci                 |
| `images/robots/versius.jpg`    | CMR Versius                        |
| `images/robots/hugo.jpg`       | Medtronic Hugo RAS                 |
| `images/robots/senhance.jpg`   | Asensus Senhance                   |
| `images/robots/mako.jpg`       | Stryker Mako                       |
| `images/robots/rosa.jpg`       | Zimmer ROSA / Smith+Nephew CORI    |

| `images/robots/dvrk.jpg`       | dVRK                               |
| `images/robots/raven.jpg`      | RAVEN II                           |
| `images/robots/star.jpg`       | STAR                               |

Recommended: 5:3 (~1000×600) jpg/png/webp. The card uses `object-fit: cover`
so anything wider/taller will be cropped to fill.
