# Robot demo videos

Each per-robot detail slide in Part 2 of `index.html` looks for a short demo
clip at the filename below. Until a file is present, the slide shows a dark
placeholder box with the expected filename.

| Filename             | Robot                                |
| -------------------- | ------------------------------------ |
| `da-vinci.mp4`       | Intuitive da Vinci (teleop)          |
| `versius.mp4`        | CMR Versius (teleop)                 |
| `hugo.mp4`           | Medtronic Hugo RAS (teleop)          |
| `senhance.mp4`       | Asensus Senhance (teleop)            |
| `mako.mp4`           | Stryker Mako (specialty)             |
| `rosa.mp4`           | Zimmer ROSA / Smith+Nephew CORI      |
| `ion.mp4`            | Intuitive Ion / Auris Monarch        |
| `preceyes.mp4`       | Preceyes / ForSight (microsurgery)   |
| `dvrk.mp4`           | da Vinci Research Kit (research)     |
| `raven.mp4`          | RAVEN II (research)                  |
| `star.mp4`           | STAR (research)                      |

Recommended format: `mp4` (H.264 / AAC), 1280×720 or 1920×1080, 5–15 seconds,
muted-friendly (no audio needed — slides play with `autoplay loop muted`).
